# Описание первой проектной работы

В проекте "Mesto" есть три основных бизнес функции: 

 - Авторизация и аутентификация пользователя
 - Управление профилем пользователя
 - Управление списком карточек

Для реализации микрофронтов я бы предложил использовать технологию Module Federation. Она обладает рядом преимуществ, которые будут полезны нам при разделении данного проекта на микрофронты: 
- Оптимальная работа с разными версиями библиотек (например одна команда может безопастно обновить версию реакта)
- Независимость разработки микрофронтендов
- Возможность использовать разные микрофронты на одном маршруте, что будет важно для работы с микрофронтами профиля пользователя и карточек


В итоге мы получим следующий список фронтов:
- host - главное приложение, которое занимается объединением всех микрофронтов в единое приложение
- auth-module - модуль управления авторизацией и аутентификацией пользователя
- profile-module - модуль управления профилем пользователя
- cards-module - модуль управления карточками, их загрузкой и дальнейшей работой
